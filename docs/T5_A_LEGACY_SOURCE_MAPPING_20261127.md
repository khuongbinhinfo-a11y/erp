## Gate kiểm nhận

- **Kho:** từng dòng xuất/trả có nguồn, lot/location, ledger duy nhất; nhập trả sau hoàn thành bị chặn; direct SQL không thể thêm issue hoặc delivery line sau chốt.
- **Đơn:** chỉ phiên bản CONFIRMED MANUAL; đủ 100% dòng thực giao đối soát; RETURNED khi trả hết, không sinh SALE/payment 0; giao thiếu ghi tiền theo snapshot.
- **Tiền:** tổng – đã thu – còn thu reconstruct từ AR/payment ledger; thua concurrency ghi 409 và không double-post; 0 là ghi nợ, không receipt.
- **Offline:** chỉ nháp/intent; bắt buộc server ACK; timeout đọc receipt rồi cùng key/body/revision mới retry.
- **RBAC:** installation/branch/warehouse, deny-by-default; read không đòi quyền cập nhật delivery cho finance.
- **Production:** CI 7/7 trên HEAD, Codex sạch; merge phụ → đồng bộ đúng Git tree chính → Vercel deploy manual READY. DB migration `0026` chỉ khi owner duyệt riêng + Codespaces operator backup encrypted, restore PG17, reconciliation. UAT thiết bị vẫn là gate riêng.

Tài liệu này thay trạng thái “MISSING T5-A” trong audit T3-A **cho riêng phạm vi code PR #98**, không biến CI thành bằng chứng production/UAT. Giữ legacy read-only.
